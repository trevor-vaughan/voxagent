# Improvements deferred until after parity

voxagent reproduces Puppet first, quirks included, because the differential
gates can only prove agreement. Some of what it reproduces is behaviour that
should eventually change. This log records those cases so the reproduction is
never mistaken for an endorsement, and so nothing has to be rediscovered once
parity is done.

## Rules

- **Parity first.** An entry here does not license changing behaviour now.
  The Puppet behaviour is implemented and gated, then logged here.
- **An entry needs evidence.** Mark each one measured (run against Puppet) or
  read (from source, with a `path:line` citation against Puppet 8.10.0).
- **Not the divergence register.** The register in `apply-spine.md` lists
  where voxagent *differs* from Puppet. This log lists where it *matches*
  Puppet but should not, eventually.
- **How an improvement ships** (default, opt-in, or a new major version) is
  decided when the first entry is taken up, not ahead of time.
