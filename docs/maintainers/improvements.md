# Improvements deferred until after parity

For maintainers. Back to the [README](../../README.md).

voxagent reproduces Puppet first, quirks included, because the differential
gates can only prove agreement. Some of what it reproduces is behaviour that
should eventually change. This log records those cases so the reproduction is
never mistaken for an endorsement, and so nothing has to be rediscovered once
parity is done.

## Rules

- **Parity first.** A logged entry does not itself license changing behaviour.
  The Puppet behaviour is implemented and gated, then logged here. Rows that begin
  "Not reproduced" are the exception: they record a Puppet behaviour voxagent
  deliberately does not reproduce, so the column holds Puppet's behaviour either way.
- **An entry needs evidence.** Mark each one measured (run against Puppet) or
  read (from source, with a `path:line` citation against Puppet 8.10.0, or against the openvox or module
  version the row names; short keys such as `pf:`, `kp:` and `uft:` are defined in
  [`apply-spine.md`](apply-spine.md)).
- **Not the divergence register.** The register in [`apply-spine.md`](apply-spine.md) (the D-numbers) lists
  where voxagent *differs* from Puppet. This log lists where it *matches*
  Puppet but should not, eventually.
- **How an improvement ships** (default, opt-in, or a new major version) is
  decided when the first entry of this kind is taken up, not ahead of time.
