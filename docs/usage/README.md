# Usage

For operators: anyone who runs voxagent or voxdiff repeatedly or from a script. New here? Start at the
[README](../../README.md).

- [Native units: `voxagent units`](units.md): the Puppet types voxagent applies itself, and how to list them.
- [What voxagent applies](resource-types.md): supported resource types, their attributes, and apply behaviour.
- [Log levels](logging.md): `--verbose` and `--debug`.
- [File backups and validation](backups.md)
- [Ruby extension host](extension-host.md): applying types voxagent does not implement natively.
- [Running against an OpenVox server](openvox-server.md): `voxagent agent`.
- [voxdiff](voxdiff.md): compare two catalog compiles or two implementations, and scan for non-deterministic constructs.
