# Security

To report a vulnerability, use the Security tab of the GitHub repository:
<https://github.com/trevor-vaughan/voxagent/security>. Do not open a public issue for a vulnerability.

Background for reporters:

- **What the agent stores and sends:** [openvox-server.md](docs/usage/openvox-server.md)
- **Trust boundaries:** [Trust model](docs/maintainers/agent-transport.md#trust-model)
